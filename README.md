## Data policy

This repository is for code and non-sensitive documentation only. Raw microdata, official input packages, client deliverables, generated outputs, QA extracts, caches, credentials, and logs must remain local and are excluded through `.gitignore`.

Each category should keep its own `README.md`, dependencies, configuration templates, source code, and changelog.
